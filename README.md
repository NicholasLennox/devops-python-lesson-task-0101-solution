# 1.1 Lesson Task – Collaborative Development

## Overview

In this lesson task you will practise a basic **feature branch workflow** — the foundation of collaborative development. You will work on a small Python utility library, adding new functions one at a time, each on its own branch.



## The Repository

The starter template contains a single utility module:

```python
# utils/math_utils.py

def add(a, b):
    return a + b
```

Your job is to extend it by adding two more functions, each developed on a separate feature branch.



## Your Tasks

### Task 1 – Multiply
Add a function called `multiply(a, b)` that returns the product of two numbers.

### Task 2 – Subtract
Add a function called `subtract(a, b)` that returns the difference of two numbers.



## Instructions

1. Fork and clone the repository.
2. Create a branch named `feature/multiply`, add the `multiply` function, commit with a clear message, merge into `main`, and delete the branch.
3. Repeat for `feature/subtract`.



## When You Are Finished

Answer the quiz questions.
